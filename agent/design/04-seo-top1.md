# SEO Top 1 Multi-formato

## Blog (actual: >=8/10)
- redactor_seo + experto_blog + Quality Gate
- FALTA: og:image, schema.org NewsArticle, alt text

## Shorts (actual: generico)
- FALTA especialista seo_youtube:
  - Titulo <=60 chars con gancho
  - Descripcion 3 hashtags + CTA
  - 10-15 tags cola larga
  - Thumbnail SDXL 1080x1920 + FFmpeg overlay texto

## Videos largos (similar shorts)
- Titulo + descripcion con timestamps
- Thumbnail 1280x720

## Podcast
- FALTA especialista seo_podcast:
  - Titulo <=100 chars
  - Descripcion keywords
  - Cover art 1400x1400

## Web
- FALTA og:title, og:description, og:image
- FALTA sitemap.xml dinamico
- FALTA robots.txt optimizado
