# Política de Privacidad

Este sitio estático (**El Encuadre**) se publica mediante páginas estáticas y prioriza la simplicidad y el respeto a la privacidad.

## Cookies y almacenamiento local
- Utilizamos `localStorage` de forma local en tu navegador únicamente para recordar tus preferencias de interfaz (como la elección de esquema claro/oscuro o el estado del aviso de consentimiento).
- No instalamos rastreadores invasivos de terceros por nuestra cuenta; si activas opciones de análisis o haces clic en enlaces externos (YouTube, X, Telegram, GitHub o medios citados), aplicarán las políticas de cada plataforma.

Para cualquier consulta sobre el sitio, puedes usar la página de [Contacto](contacto.md).
