# Glosario de técnicas de manipulación y sesgos

Esta es la base de datos de Somos El Encuadre. Cada día analizamos una noticia usando estas herramientas.

| Técnica | Definición | Autor de referencia |
|---------|-----------|---------------------|
| **Framing** | Seleccionar aspectos de la realidad para hacerlos más prominentes. | Bernays, 1928 |
| **Anchoring** | Dar un dato inicial para condicionar la percepción. | Kahneman, 2011 |
| **Omisión** | No mencionar un tema relevante de forma deliberada. | Chomsky, 1988 |
| **Agenda-setting** | Los medios no dicen qué pensar, pero sí sobre qué pensar. | Lippmann, 1922 |
| **Priming** | Exponer a un estímulo previo que influye en la respuesta. | Kahneman, 2011 |
| **Bandwagon** | Hacer creer que todo el mundo lo hace para que te unas. | Le Bon, 1895 |
| **Testimonial** | Usar a un famoso para que apoye una idea. | Bernays, 1928 |
| **Transfer** | Asociar una idea con algo que ya respetas. | Bernays, 1928 |
| **Card Stacking** | Presentar solo los datos que te favorecen. | Chomsky, 1988 |
| **Glittering Generalities** | Usar palabras bonitas sin contenido real. | Bernays, 1928 |
| **Name Calling** | Descalificar al oponente con etiquetas. | Bernays, 1928 |
| **Plain Folks** | Parecer uno más del pueblo para ganar confianza. | Bernays, 1928 |
| **Fear Appeal** | Generar miedo para que aceptes una solución. | Le Bon, 1895 |
| **Scarcity** | Hacer creer que algo es escaso para que corras. | Cialdini, 1984 |
| **Confirmation Bias** | Solo ver lo que confirma tus creencias. | Kahneman, 2011 |
| **Halo Effect** | Pensar que alguien es bueno en todo por ser bueno en una cosa. | Kahneman, 2011 |
| **Availability Heuristic** | Creer que algo es más probable porque lo recuerdas mejor. | Kahneman, 2011 |
| **Dunning-Kruger** | No saber lo suficiente para saber que no sabes. | Dunning, 1999 |
| **Sunk Cost** | Seguir invirtiendo en algo solo porque ya has invertido. | Kahneman, 2011 |
| **Gambler's Fallacy** | Creer que si algo no ha pasado, es más probable que pase. | Kahneman, 2011 |
| **Authority Bias** | Creer algo solo porque lo dice una autoridad. | Cialdini, 1984 |
| **In-group Bias** | Favorecer a los que son como tú. | Le Bon, 1895 |
| **Negativity Bias** | Dar más peso a las noticias negativas. | Kahneman, 2011 |
| **Recency Bias** | Dar más peso a lo último que has oído. | Kahneman, 2011 |
| **Illusory Truth Effect** | Creer que algo es verdad porque lo has oído muchas veces. | Kahneman, 2011 |
| **Bait-and-Switch** | Prometer algo y dar otra cosa. | Chomsky, 1988 |
| **False Dilemma** | Presentar solo dos opciones para forzar una elección. | Bernays, 1928 |
| **Slippery Slope** | Decir que un pequeño paso llevará a un desastre. | Chomsky, 1988 |
| **Straw Man** | Atacar una versión exagerada del argumento del otro. | Chomsky, 1988 |
| **Appeal to Emotion** | Manipular las emociones para ganar el debate. | Bernays, 1928 |
| **Ad Hominem** | Atacar a la persona en vez del argumento. | Chomsky, 1988 |
| **Cherry Picking** | Elegir solo los datos que te convienen. | Chomsky, 1988 |
| **Tu Quoque** | Desviar la atención diciendo que el otro también lo hace. | Chomsky, 1988 |
| **Load Ad** | Preguntar algo que ya asume una respuesta. | Bernays, 1928 |
| **Questioning** | Repetir una pregunta hasta que parezca un hecho. | Bernays, 1928 |
| **Overton Window** | Lo que es aceptable decir en cada momento. | Overton, 1994 |
| **Manufacturing Consent** | Fabricar el consentimiento público con propaganda. | Chomsky, 1988 |
| **Diversion** | Desviar la atención de lo importante con algo trivial. | Bernays, 1928 |
| **Gradual Change** | Aplicar un cambio poco a poco para que no se note. | Bernays, 1928 |
| **Dehumanization** | Hacer ver a un grupo como menos humano. | Le Bon, 1895 |
| **Polarization** | Dividir a la sociedad en dos bandos. | Le Bon, 1895 |
| **Emotional Contagion** | Contagiar emociones a través de la multitud. | Le Bon, 1895 |
| **Crowd Psychology** | La masa actúa como un solo ser. | Le Bon, 1895 |
| **Suggestion** | Sugerir ideas sin que parezca una orden. | Le Bon, 1895 |
| **Prestige Effect** | Lo que dice alguien con prestigio se cree sin dudar. | Le Bon, 1895 |
| **Repetition** | Repetir algo para que se grabe. | Le Bon, 1895 |
| **Assertion** | Afirmar algo sin pruebas. | Le Bon, 1895 |
| **Contagion** | Las ideas se contagian como virus. | Le Bon, 1895 |
| **Illusion of Control** | Creer que controlas algo que no controlas. | Kahneman, 2011 |
| **Planning Fallacy** | Creer que todo saldrá más rápido de lo que sale. | Kahneman, 2011 |
| **Reactance** | Hacer lo contrario si te dicen lo que tienes que hacer. | Brehm, 1966 |
